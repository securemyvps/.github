# SecureMyVPS

Open-source VPS security hardening tools — built to be transparent, verifiable, and safe to inspect before you run.

- Website: [securemyvps.com](https://securemyvps.com)
- Main repository: [securemyvps/securemyvps](https://github.com/securemyvps/securemyvps)

## Security & Transparency

- Every official release is tagged immutably (`v*`), accompanied by `SHA256SUMS.txt` checksums and GitHub Build Provenance attestations.
- All CI workflows run with least-privilege tokens and full-length commit-SHA pinned actions.
- Found a security issue? Please report it privately via **GitHub Private Vulnerability Reporting** (see [`SECURITY.md`](https://github.com/securemyvps/.github/blob/main/SECURITY.md)).
